# KPI Metrics

## Purpose

Defines how success is measured.

## Core Metrics

### Participation

- Number of active students
- Number of completed sessions
- Average sessions per student

### Fluency

- Average improvement score
- Assessment pass rate
- Level advancement rate

### Retention

- Completion rate
- Drop-off rate
- Weekly engagement

### Quality

- Session verification rate
- Instructor approval rate
- Fraud detection incidents

### Reputation

- Average reputation score
- Mentor conversion rate
- Partner satisfaction rating

### Certification

- Certificates issued
- Level distribution
- Reassessment rate

## Advanced Metrics

- Workforce placement (future)
- Bilingual job readiness
- Mentor network growth
- Cross-language expansion

## Core Principle

Measure what proves fluency.
