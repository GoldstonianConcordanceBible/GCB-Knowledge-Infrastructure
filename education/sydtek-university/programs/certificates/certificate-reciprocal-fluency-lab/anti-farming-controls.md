# Anti-Farming Controls

## Purpose

This document defines controls that protect the Fluency Lab from fake activity, low-quality participation, and reward abuse.

## Risk

Any learned-and-earned system can be abused if rewards are easier to earn than real skill.

## Primary Threats

- Fake session logs
- Silent attendance
- Multiple accounts
- Partner collusion
- Scripted conversations
- AI-generated reflections
- Reward farming
- Low-quality referrals

## Required Controls

### Partner Verification

Both partners must verify each session.

### Random Audits

Instructors may request recordings or live checks.

### Recorded Samples

Students must submit speaking samples at key points.

### Live Final Exam

Certification requires live oral assessment.

### Instructor Approval

No final status is issued automatically.

### Session Quality Review

Sessions must include speaking, listening, correction, and reflection.

## Red Flags

Review is required when:

- Sessions are completed too quickly
- Logs are identical
- Partners only verify each other repeatedly
- Reflections appear copied
- Speaking level does not match claimed hours
- Student avoids live assessment

## Consequences

Program leadership may:

- Reject sessions
- Require reassessment
- Pause certification
- Remove reward eligibility
- Remove student from program

## Core Principle

The system must protect the value of the certificate.
