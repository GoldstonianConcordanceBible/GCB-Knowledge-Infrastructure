# Program Roadmap

## Phase 0 — GitHub Lock-In

Create canonical documentation.

Files:

- README.md
- program-overview.md
- certificate.yaml
- assessment-rubric.md
- learned-and-earned-model.md
- token-guardrails.md
- anti-farming-controls.md
- governance-model.md

## Phase 1 — Manual Pilot

Run the program manually with a small group.

Goals:

- Test partner matching
- Test session logs
- Test rubrics
- Test final oral exam
- Identify fraud risks

## Phase 2 — Certificate Pilot

Issue first certificates only after full assessment.

Goals:

- Validate scoring
- Collect speaking samples
- Review student feedback
- Refine instructor guide

## Phase 3 — Mentor Layer

Allow certified students to become peer mentors.

Goals:

- Build internal support network
- Reward verified service
- Reduce instructor workload
- Expand partner matching capacity

## Phase 4 — Workforce Alignment

Connect certificates to practical pathways.

Goals:

- Trade school integration
- Customer service readiness
- Ministry outreach
- Homeschool pathway
- Adult education pathway

## Phase 5 — Platform Build

Develop custom SydTek Fluency platform.

Features:

- Registration
- Partner matching
- Session logs
- Recording uploads
- Rubric scoring
- Certificate issuance
- Reputation dashboard

## Phase 6 — Token-Aware Layer

Only after the certificate system works.

Goals:

- Limited reward recognition
- Scholarship pools
- Mentor recognition
- Governance participation

## Core Principle

Build proof before rewards.
