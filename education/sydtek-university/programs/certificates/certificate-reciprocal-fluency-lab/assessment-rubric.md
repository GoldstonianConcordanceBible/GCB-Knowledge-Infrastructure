# Assessment Rubric

## Scale

1 = Beginning  
2 = Developing  
3 = Functional  
4 = Proficient  
5 = Fluent for Level  

## Speaking

| Score | Description |
|---|---|
| 1 | Can say isolated words |
| 2 | Can form short phrases |
| 3 | Can answer simple questions |
| 4 | Can maintain basic conversation |
| 5 | Can speak naturally for the level |

## Listening

| Score | Description |
|---|---|
| 1 | Understands very little spoken language |
| 2 | Recognizes familiar words |
| 3 | Understands simple sentences |
| 4 | Understands partner in guided conversation |
| 5 | Understands natural speech for the level |

## Pronunciation

| Score | Description |
|---|---|
| 1 | Frequently unclear |
| 2 | Understandable with effort |
| 3 | Mostly understandable |
| 4 | Clear with minor errors |
| 5 | Clear and natural for the level |

## Response Speed

| Score | Description |
|---|---|
| 1 | Cannot respond without long pauses |
| 2 | Responds slowly with help |
| 3 | Responds to familiar prompts |
| 4 | Responds with growing confidence |
| 5 | Responds naturally for the level |

## Correction Response

| Score | Description |
|---|---|
| 1 | Struggles to repeat corrections |
| 2 | Repeats correction with difficulty |
| 3 | Accepts and applies correction |
| 4 | Applies correction in later conversation |
| 5 | Self-corrects during live speech |

## Certification Standard

A student must average at least 3.0 across all categories to receive basic certification.

A student must average at least 4.0 to receive proficient certification.
