# Point-Based Rubrics

This folder contains point-based grading versions of the major certificate rubrics.

These versions are useful when instructors want more explicit scoring guidance while preserving the same qualitative standards already established in the course-level rubric files.

---

## Purpose

Point-based rubrics help instructors:

- grade more consistently
- explain scores more clearly
- speed up evaluation
- support moderation across sections
- give students more transparent expectations

## Use Note

Programs may use these rubrics directly or adapt point weights to local policy.

The key principle is that scoring should still reward:

- clarity
- realism
- systems thinking
- ethical seriousness
- practical recommendation quality
- professional communication
