# Model Artifacts

This folder contains sample student artifact formats for the certificate.

These are not meant to be copied directly.
They are meant to show students what strong structure, tone, and organization look like.

---

## Purpose

These examples help students see:

- how to title work clearly
- how to organize analysis
- how to write in a professional tone
- how to connect evidence to recommendations
- how to prepare portfolio-worthy submissions

---

## Suggested Files

- `model-sscm-101-supply-chain-map-explanation.md`
- `model-sscm-201-board-memo.md`
- `model-sscm-301-technology-recommendation-brief.md`
- `model-sscm-401-executive-summary.md`

---

## Faculty Note

Instructors should use these as structure examples, not answer keys.

Students should still be required to think independently, develop their own judgment, and adapt their work to the specific case or organization they are analyzing.
