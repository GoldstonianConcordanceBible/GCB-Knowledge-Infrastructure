# GitHub Evidence Statement
## Certificate in Sustainable Supply Chain Management & Corporate Social Responsibility

This document explains why GitHub is used as an instructional, archival, and evidence-bearing layer for this certificate.

---

## Purpose

GitHub serves as the program’s structured evidence environment.

Rather than relying only on closed learning systems, this certificate uses repository-based organization so that curriculum materials, assignments, rubrics, and portfolio artifacts can be documented clearly and reviewed consistently.

---

## What GitHub Stores in This Program

GitHub may store:

- program guides
- syllabi
- assignment prompts
- rubrics
- course notes
- case-study folders
- student portfolio artifacts
- capstone strategy reports
- revision history where appropriate

---

## Why This Matters

A repository-based model supports:

- transparency
- version control
- clearer organization
- portfolio portability
- faculty review
- long-term auditability
- structured academic evidence

This is especially useful for programs that want visible proof of learning rather than only gradebook entries.

---

## Educational Value

Using GitHub in this certificate helps students learn to:

- organize work clearly
- present evidence professionally
- revise documents responsibly
- maintain versioned records
- communicate in a modern digital workflow

These are useful academic and workforce habits.

---

## Review Value

For faculty or external reviewers, a GitHub-based evidence model can make it easier to examine:

- what the program teaches
- how assignments are structured
- what standards are used
- what students actually produce
- how capstone work develops over time

---

## Portfolio Value

Student work stored in organized folders can function as a lightweight professional portfolio.

This is especially valuable in a certificate like this, where the strongest proof of competence is often:

- a memo
- a strategy brief
- a risk map
- a transformation plan
- a clearly documented analysis

---

## Program Integrity Statement

GitHub is used here as a documentation and evidence layer.
It does not replace thoughtful teaching, faculty judgment, or appropriate privacy standards.

Where student privacy or institutional policy requires limitations, programs may:

- use private repositories
- anonymize submissions
- separate public-facing and internal evidence layers
- restrict access by role

---

## Recommended Practice

Program leadership should maintain:

- consistent folder naming
- stable course file structure
- clear rubric placement
- portfolio expectations
- revision control discipline

This improves program credibility and makes later review much easier.
