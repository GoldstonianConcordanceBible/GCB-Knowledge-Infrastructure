# SSCM 101 Discussion Bank

This folder contains discussion prompts for SSCM 101.

## Purpose

These prompts help students move from basic definitions to systems thinking.

They are designed to push students beyond memorization and into analysis.

## Recommended Use

Faculty may use these prompts for:

- weekly discussion boards
- live seminar prompts
- written reflections
- peer response exercises
- oral discussion in scholars settings
