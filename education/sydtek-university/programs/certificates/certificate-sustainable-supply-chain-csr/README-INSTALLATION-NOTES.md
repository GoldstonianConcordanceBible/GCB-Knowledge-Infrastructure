# Installation / Repo Seeding Notes

## Purpose

These notes help seed the certificate into a new GitHub repository cleanly.

---

## Suggested Setup Order

1. Create the repository root
2. Add:
   - `README.md`
   - `PROGRAM_GUIDE.md`
   - `ADMISSIONS.md`
   - `CAREER_OUTCOMES.md`
   - `FACULTY_NOTES.md`
   - `github-evidence-statement.md`
   - `CITATION.cff`
   - `LICENSE`
   - `.gitignore`
   - `RELEASE_NOTES.md`
3. Add the four course folders
4. Add assignments, rubrics, discussions, and case studies
5. Add portfolio and model-artifact folders
6. Add accreditation and instructor-operation files
7. Commit as `v1.0.0-initial-certificate-build`

## Final Check Before Publish

- Confirm every folder has a README where needed
- Confirm file naming is consistent
- Confirm terminology stays consistent across SydTek University and SydTek Scholars
- Confirm version is noted in `RELEASE_NOTES.md`
- Confirm license and citation file are present
