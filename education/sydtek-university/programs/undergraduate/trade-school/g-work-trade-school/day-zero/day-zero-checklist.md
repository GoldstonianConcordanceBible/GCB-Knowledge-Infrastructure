# Day Zero Checklist

## Pre-Launch Setup

- [ ] Confirm pilot city
- [ ] Create worker intake form
- [ ] Create customer request form
- [ ] Create manual verification spreadsheet
- [ ] Create job tracker
- [ ] Create review form
- [ ] Create Digital Union badge draft
- [ ] Identify first 10 to 25 workers
- [ ] Identify first 5 to 10 customers

## Worker Intake

- [ ] Full name
- [ ] Phone number
- [ ] Email
- [ ] City
- [ ] Trade specialty
- [ ] Years of experience
- [ ] License status
- [ ] Insurance status
- [ ] Portfolio photos
- [ ] References
- [ ] Availability
- [ ] Service radius

## Customer Intake

- [ ] Customer name
- [ ] Phone number
- [ ] Email
- [ ] Job type
- [ ] Job urgency
- [ ] Location
- [ ] Description of issue
- [ ] Photos if available
- [ ] Preferred time window
- [ ] Budget range if known

## Manual Verification

- [ ] Confirm identity
- [ ] Review license if applicable
- [ ] Review insurance if applicable
- [ ] Review photos of past work
- [ ] Call or text reference
- [ ] Confirm communication reliability
- [ ] Assign provisional status

## First Job Flow

- [ ] Customer submits request
- [ ] Admin reviews job
- [ ] Admin matches worker
- [ ] Worker confirms availability
- [ ] Customer confirms booking
- [ ] Job completed
- [ ] Customer leaves review
- [ ] Worker status updated

## End of Day Zero Review

- [ ] How many workers were onboarded?
- [ ] How many jobs were completed?
- [ ] What was average response time?
- [ ] What was customer satisfaction?
- [ ] Which workers performed best?
- [ ] What failed?
- [ ] What should be automated first?
