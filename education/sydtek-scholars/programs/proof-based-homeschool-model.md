# SydTek Scholars Proof-Based Homeschool Model

## Purpose

This document defines the SydTek Scholars homeschool model as the first accreditation-facing pathway in the ecosystem.

## Institution

SydTek Scholars

## Parent Institution

SydTek University

## Root Framework

Goldstonian Concordance Bible (GCB)

## Doctrine

Fluency, not exposure.

## Method

Mirror → Water → Fire

## Core Thesis

A homeschool student should not merely complete lessons.

A homeschool student should demonstrate mastery through reading, speaking, writing, creating, practicing, and presenting.

## Why SydTek Scholars Comes First

SydTek Scholars is the natural first accreditation-facing layer because it provides:

- Clear learner records
- Family-based instruction
- Structured curriculum
- Portfolio evidence
- Measurable progress
- Repeatable assessments
- Long-term student formation

## Educational Model

SydTek Scholars uses:

- Parent-guided instruction
- Digital curriculum
- Portfolio-based assessment
- Oral demonstrations
- Reading logs
- Writing samples
- Project evidence
- Faith-integrated learning
- Mastery checkpoints

## Core Learner Evidence

Each student maintains:

- Reading portfolio
- Writing portfolio
- Math progress evidence
- Language fluency evidence
- Scripture memory evidence
- Project-based learning evidence
- Parent/instructor notes
- Assessment records

## Accreditation Positioning

SydTek Scholars should prepare evidence for:

- Curriculum scope and sequence
- Attendance and participation
- Student progress
- Assessment methods
- Parent/instructor roles
- Learning outcomes
- Portfolio review
- Student safety and privacy

## Core Principle

The homeschool becomes credible when learning is documented, assessed, and demonstrated.
