# $GCB Token Flow Across the SydTek Structure

## Purpose

Defines how $GCB may interact with GCB, SydTek University, SydTek Scholars, and certificate programs.

---

## Core Rule

$GCB supports the ecosystem.

$GCB does not control doctrine.

---

## Layered Token Role

### GCB Layer

$GCB may support:

- Repository funding
- Dataset releases
- Knowledge graph maintenance
- Preservation work
- Public research infrastructure

It may not vote to change doctrine.

---

### SydTek University DAO

$GCB may support:

- Program governance
- Certificate development
- Instructor incentives
- Scholarship pools
- Mentor recognition
- Platform development

---

### SydTek Scholars DAO

$GCB may support:

- Family learning scholarships
- K–12 curriculum access
- Student challenges
- Parent-led programs
- Youth learning pathways

---

## Token Utility

Approved utility may include:

- Scholarship funding
- Advanced certificate access
- Mentor recognition
- Governance participation
- Curriculum contribution review
- Platform feature access

---

## Token Restrictions

$GCB must not be used to:

- Buy certificates
- Skip assessments
- Override instructor judgment
- Vote away doctrine
- Create pay-to-pass outcomes

---

## Core Principle

The token funds the mission.

It does not define the mission.
