# On-Chain Privacy Policy

## Purpose

Protects student privacy when using blockchain verification.

## Core Rule

Never place sensitive student data directly on-chain.

## Prohibited On-Chain Data

Do not publish:

- Full legal names
- Student ages
- Addresses
- Emails
- Phone numbers
- Private recordings
- Assessment notes
- Session logs
- Family information

## Allowed Public Data

Public metadata may include:

- Program name
- Credential type
- Certification level
- Issue date
- Status
- Verification hash

## Private Data Storage

Private data should remain in:

- Institutional records
- Secure storage
- Access-controlled archives

## Hashing

A hash may prove that a record existed without exposing the record itself.

## Core Principle

Verification should not sacrifice privacy.
