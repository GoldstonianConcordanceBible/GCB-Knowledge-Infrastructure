# Wallet Recovery Policy

## Purpose

Defines how students may recover or rebind credentials if wallet access is lost.

## Core Problem

Wallets can be lost.

Fluency should not be lost because a private key was lost.

## Recovery Process

1. Student submits recovery request
2. Identity and certificate record are reviewed
3. Original credential is marked replaced or revoked
4. New credential is issued to verified wallet
5. Recovery event is documented

## Required Evidence

- Certificate ID
- Student identity verification
- Prior assessment record
- Instructor or institutional confirmation

## Public Record

Public record may show:

- Original credential status changed
- Replacement credential issued
- Recovery date

## Privacy Rule

Do not publish sensitive identity details.

## Core Principle

A wallet holds the record.

The learner holds the achievement.
